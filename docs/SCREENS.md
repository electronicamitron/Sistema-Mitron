# Pantallas (Screens)

- **Dashboard**: Muestra 4 KPI (`StatCard`) principales (Ingresos, Gastos, Compras, Estado de Inventario).
- **Administración**: 
  - Centraliza las operaciones principales.
  - Consta de 3 pestañas: Ingresos (ventas importadas), Gastos (facturas importadas), Proveedores (catálogo).
  - Incluye el botón maestro de "Importar archivo".
- **Inventario**: Listado de existencias, filtros agrupados en `FilterBar` y acceso al `StockConfigModal`.
- **Catálogo**: Relación de productos, costos y códigos externos.
- **Calendario**: Vista mensual para control de vencimientos y eventos operativos.
