# Catálogo de Componentes

## Componentes UI Base (`components/ui/`)
- **Button**: Botón estándar con variantes `primary`, `secondary`, `ghost` y `danger`. Controla interacciones principales.
- **Input / Select / SearchField**: Controles de formulario con estilo oscuro y bordes discretos.
- **Badge**: Indicador visual semántico para estados (éxito, atención, error, neutral).
- **DataTable**: Tabla adaptable para listado de datos con cabeceras fijas.
- **EmptyState**: Mensaje sobrio cuando un listado no contiene registros.
- **Modal**: Ventana emergente central (ej. Calculadora de precios).
- **Drawer**: Panel lateral deslizable (ej. Ficha de proveedor, detalle extendido).
- **StatCard**: Tarjeta de KPI para Dashboards y resúmenes.

## Componentes de Dominio (`components/domain/`)
- **NotificationPanel**: Desplegable desde la campana, lista las notificaciones prioritarias.
- **PriceCalculatorModal**: Herramienta de cálculo (Costo -> Margen -> Precio + IVA).
- **StockConfigModal**: Modal compacto con *stepper* (-/+) para ajustar límite de stock mínimo.
- **SupplierDrawer**: Panel lateral con el resumen, contacto y facturas de un proveedor.
